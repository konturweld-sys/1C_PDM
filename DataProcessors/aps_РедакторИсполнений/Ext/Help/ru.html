Обработка предназначена для формирования составов нескольких исполнений. Для начала выберите нужные исполнения в списке и нажмите на кнопку "Редактировать".  В главном окне отображается состав исполнений; при активизации строки в нижнем окне отображаются атрибуты вхождения соответствующего элемента в исполнения.

Если в состав какого-либо исполнения изделие входит в количестве "0", то в редакторе в поле "Количество" будет указано значение "Истина".

В окне редактора исполнений можно изменять атрибуты элемента состава: наименование, обозначение, формат. Если один или несколько элементов были заблокированы на редактирование или пользователь не имеет права его изменения, то это изделие будет доступно только для чтения. В табличное поле состава можно перетаскивать (заимствовать) элементы из окон "Поиск", "Управление структурой изделия", "Конструкторско-технологический справочник" и др. По кнопке "Добавить" можно заимствовать существующий элемент из окна проводника. Для заполнения группы ячеек с количеством нажмите кнопку "Заполнить количество" и укажите параметры заполнения (строка, столбец или матрица).

Если для изделия указано количество "0" или "Ложь", то он будет вырезан из состава исполнения; в противном случае - добавлен в состав исполнения. При нажатии на кнопку "Принять изменения" состав всех исполнений будет очищен и сформирован заново с учетом внесенных изменений.
