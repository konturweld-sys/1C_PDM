Специальное прикрепленное окно, которое называется "Свойства" Окно контекстно вызывается из любого места системы при выделении элемента. Окно информации состоит из четырех свитков, каждый из которых содержит свою часть информации об элементе.

Общая информация

Общая информация содержит основные параметры элемента в системе, такие как представление, наименование, обозначение, владельца и номер ревизии.

Представление — текстовая строка, содержащая представление элемента. Если требуется копировать значение представления, выделите его в данном поле и нажмите Ctrl+C

Вид элемента — определяет вид элемента. Нажатие на гиперссылку вида вызывает окно описания вида элемента.

Наименование — отдельно вынесенное поле параметра наименования элемента. Возможно, чтение и изменение в рамках прав доступа.

Обозначение — отдельно вынесенное поле параметра обозначение. Возможно, изменение в рамках прав доступа.

Ревизия — отображает идентификатор ревизии, если выделенный элемент является ревизией. При необходимости Вы можете создать ревизию, воспользовавшись гиперссылкой. Создать....

Состояние — гиперссылка определяющее текущее состояние элемента. По нажатию на нее вы инициируете бизнес-процесс изменения состояния элемента.

Владелец — пользователь, который установлен владельцем данного элемента. Владельца может изменить сам владелец элемента или администратор системы.

Владельцем может быть и системная группа.

Группа — группа пользователей, которая также является владельцем элемента.

Редактируется — если элемент редактируется, то в этом поле отображается редактирующий пользователь, а при нажатии на конверт справа система инициирует уведомление этому пользователю.

Рейтинг

На свитке рейтинг отображается рейтинг текущего элемента, установленный по определенному набору критериев. По нажатию на гиперссылку Начать оценку... вызывается окно оценки элементов. Если элемент не оценен по набору критериев поле рейтинга пустое.

Параметры

В этом свитке отображается дерево параметров элемента, назначенных ему создании. Набор этих параметров может быть изменен. Параметры в дерево добавляются аналогично добавлением таких параметров в окне создания элементов. Параметры тоже имеют права доступа и, возможно, значение параметра вы не сможете изменить.

Представление

Представление отвечает за отображение элемента в системе и состоит из списка строк, в которых указан текст или параметр. Набор строк в представлении определяет фактическое значение представления. Если в строке содержится пробел, то такая строка отображается в виде "Пробелы (число пробелов)". Текстовая строка в списке представления отображается синим цветом. Последовательность строк, начиная с верхней и далее вниз, определяет последовательность формирования представления (слева направо). В формировании представления могут быть задействованы все параметры элемента.

Для создания представления необходимо:

1. Открыть окно свойств элемента

2. Открыть свитки Параметры и Представление

3. Определиться с последовательностью использования параметров в представлении

4. Выделить в дереве необходимый параметр элемента и нажать гиперссылку Добавить в представление

5. Добавить в список представления строки с пробелами, которые будут разделять значения свойств.

6. Нажать кнопку Применить в окне информации об элементе.

7. Убедиться в правильности сформированного представления и при необходимости скорректировать, удалив или добавив соответствующие параметры.

После любого изменения в окне информации об элементе для принятия этих изменений требуется нажать кнопку Применить.
