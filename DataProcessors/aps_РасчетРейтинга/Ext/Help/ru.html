Обработка предназначена для персональной оценки элемента по выбранному набору критериев. Для каждого критерия нужно выбрать оценку из списка.

При нажатии на кнопку "Оценить" происходит перерасчет общего рейтинга элемента в зависимости от выбранных значений и весовых коэффициентов по каждому критерию.
