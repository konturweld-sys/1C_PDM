Создание нового элемента

При создании любого элемента необходимо указать его вид и параметры. Вид элемента вибирается из иерархического списка. Набор параметров для каждого из видов элемента различный, но некоторые параметры могут быть одинаковыми. Параметры добавляются и удаляются при помощи командной панели.

Параметры объединяются в группы. Группы в некоторых случаях несут смысловую нагрузку и могут влиять на выбор ревизий в правилах управления, но чаще всего они просто выполняют объединяющую функцию параметров имеющих сходное назначение. Создание собственной группы осуществляется при помощи командной панели

Это нужно знать!

  • Изменения, которые вы вносите в этом окне, влияют только на создаваемый элемент и не влияют на созданные элементы и создаваемые в будущем.
  • Параметры не могут иметь одинаковое наименование в рамках одного элемента
  • При создании параметры наследуют права доступа элемента
  • Значение некоторых параметров задается автоматически
  • Помимо даты создания элемента как параметра имеется внутренняя дата, которую нельзя изменить.

 

Параметры внутри групп создаются и удаляются также при помощи командной панели. При добавлении новых параметров важно помнить несколько простых правил:

Это нужно знать!

  • Параметры не должны иметь одинаковое наименование
  • Тип значения, который можно задать параметру определяется свойством этого параметра
  • Некоторые параметры имеют значение по умолчанию
  • Для каждого параметра должно быть указано свойство

 

После указания необходимых параметров и нажатия кнопки Далее элемент будет создан.

Где найти?

Список, назначение, а также обязательность использования параметров всех элементов смотрите в приложении 1 к руководству.

 

Если вы установите флаг Создать номенклатурную позицию, то после создания элементов вам будет предложено создать номенклатурную позицию этого элемента в системе ERP. Если Вы указали флаг создания нескольких элементов, то система после создания элемента будет возвращать вас в окно параметров для создания следующего до тех пор, пока вы не снимите флаг. Создаваемый элемент размещается в личных папках, либо в структуре изделия, где он создается.

Создание номенклатурной позиции при создании элемента (только для личных папок и проводника)

Для того чтобы система 1C:PDM правильно работала с ERP-системами, такими как "1С:Управление производственным предприятием" или другими, каждый элемент должен быть связан с номенклатурным справочником системы ERP. Чем раньше это будет сделано, тем легче в дальнейшем будет производиться процесс взаимодействия. Элементы сложного изделия лучше связывать с номенклатурой как можно ранее. Справочник номенклатуры достаточно большой и большая часть информации в нем не относится напрямую к конструкторско-технологической подготовке производства, однако, ряд свойств все же необходимо знать и указывать при создании элементов.

Где найти?

Полное описание справочника номенклатуры ищите в документации на "1С:Управление производственным предприятием"

 

Это нужно знать!

Создавать номенклатурную позицию необходимо только для материальных сущностей (изделий, деталей и т.д.) и, в некоторых случаях, для средств технологического оснащения.

 

При создании позиции номенклатуры, которая будет связана с элементом изделия, Вам нужно задать четыре обязательных поля:

Вид номенклатуры – вид, определяющий данную номенклатуру. Чаще всего указывается "Товар".

Группа номенклатуры – папка в которой будет размещена новая создаваемая позиция номенклатуры.

Базовая единица измерения – единица измерения, при помощи которой осуществляется пересчет всех дополнительных единиц.

Вид воспроизводства – указывает воспроизводство данной номенклатуры (покупка, производство и т.д.)
