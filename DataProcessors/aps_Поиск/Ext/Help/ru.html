Обработка поиска элементов и документов в системе. Окно интерактивного поиска состоит из панели быстрого поиска и нескольких свитков, каждый из которых содержит дополнительные атрибуты поиска.

 

Быстрый поиск

Располагается в верхней части окна. Быстрый поиск - поиск элемента по представлению. Можно сузить область поиска, указав нужный вид элемента из списка.

Также на панели быстрого поиска расположена кнопка "Только мои элементы". При ее включении поиск осуществляется только среди элементов, владельцем которых Вы являетесь. Чтобы выполнить поиск среди файлов документов требуется установить переключатель "Искать среди" в соответствующее положение.

 

Дата

Для поиска элементов, созданных за указанный промежуток времени, предназначены поля "Создан не ранее", "Создан не позже". Можно воспользоваться предопределенными настройками (Сегодня, Вчера, За последний месяц и др.).

 

Примечание:

Системную (внутреннюю) дату не следует путать с параметром "Дата создания"

 

Владелец и группа

Поиск по владельцу и группе-владельцу. В качестве владельца можно выбрать системную группу.

 

Ревизии и состояния

В текущем свитке задаются условия для поиска элементов, находящихся в определенном состоянии, а также ревизий изменения и исполнения. Аналогичные условия можно задать в свитке "Свойства".

 

Свойства

Список свойств, на которые накладываются условия, может быть произвольным. Для каждого свойства задается вид сравнения (по умолчанию Равно) и значение. Если значение не заполнено - условие будет игнорировано.

Есть возможность автозаполнения списка свойств в соответствии с выбранным видом элемента.

 

Расширенный поиск

Условия расширенного поиска задаются на встроенном языке платформы. В поле "Условия поиска" из списка можно выбрать заранее созданное условие поиска или создать новое.

 

Результаты поиска отображаются в отдельном прикрепленном окне. Найденные элементы можно открыть в любом интерфейсе, посмотреть информацию, применяемость и пр.
