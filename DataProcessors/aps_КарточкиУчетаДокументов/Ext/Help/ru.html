Обработка предназначена для просмотра и создания карточек учета документов из окна управления структурой изделия.

Если при запуске обработки активным элементом в окне управления структурой изделия является документ, то будет создана и открыта его карточка учета. Для просмотра существующих карточек документов в дереве состава выделите нужное изделие и запустите данную обработку. В открывшемся окне отображается структура изделия и существующие карточки учета, просмотреть которые возможно по кнопке открытия. Для создания карточек учета документов на все изделие выделите его флажком. В поле "Инвентарная книга" необходимо указать группу из справочника инвентарных книг, в которой будут созданы карточки учета. При нажатии на кнопку "Выполнить" будут созданы недостающие карточки учета документов для выбранных документов.
