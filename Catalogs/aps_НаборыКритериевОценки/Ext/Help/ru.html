Справочник предназначен для объединения нескольких критериев в набор, по которому в итоге производится оценка. Для каждого критерия из набора определяется его вес - коэффициент умножения оценки по данному критерию (по умолчанию равен единице). Чем больше вес критерия в наборе, тем суммарная оценка ближе к значению оценки по данному критерию.
