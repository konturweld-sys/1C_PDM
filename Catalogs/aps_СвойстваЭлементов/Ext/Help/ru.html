Справочник подчинен справочнику "Виды элементов" и позволяет указать необходимые свойства для выбранного вида по умолчанию. Добавление новых свойств осуществляется выбором свойства из плана видов характеристик "Свойства", с указанием возможного значения и единицы измерения по умолчанию для заданного свойства.

Для свойства можно указать дополнительные параметры:

  • Необязательное при незаполненном - если значение свойства не заполнено, свойство игнорируется;
  • Выбор по маске - свойство заполняется по маске (строковые свойства, например, обозначение);
  • Пустое недопустимо - заполнение свойства является обязательным, в противном случае - сообщение об ошибке.
