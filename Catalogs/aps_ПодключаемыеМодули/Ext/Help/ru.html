Справочник содержит список всех подключаемых модулей (плагинов).

Существует два способа подключения плагинов:

  • С помощью механизма авторегистрации модулей;
  • Вручную, путем создания новых элементов в справочнике.

Для того чтобы подключить плагин первым способом, нажмите кнопку "Авторегистрация" на командной панели формы. Откроется диалог открытия файла (режим множественного выбора). После выбора файлов внешних обработок откроется форма регистрации новых подключаемых модулей. Нажмите кнопку "Выполнить". В справочнике будут автоматически созданы новые элементы с уже заполненными атрибутами. Каждый плагин соответствует выбранной обработке.

Для подключения модуля вручную создайте новый элемент в справочнике. В поле "Наименование" введите название плагина. В поле "Обработка" выберите обработку из списка, в случае подключения плагина как объекта конфигурации, или файл, в случае подключения плагина как внешней обработки (файл обработки помещается в базу данных). Обработку, находящуюся в базе данных, можно сохранить на диск. Для того чтобы автоматически заполнить атрибуты плагина, нажмите на кнопку "Автозаполнение" на командной панели формы подключаемого модуля. В поле "Картинка" опционально можно указать картинку кнопки из библиотеки. Для плагина необходимо указать интерфейсы и подменю (выбираются из списка), в которых он будет отображаться. Есть возможность разграничения доступа к плагину по ролям.
